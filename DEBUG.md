# DEBUG.md

Опис реальних помилок, які виникали під час роботи над проєктом, за формулою:
**команда → текст помилки → причина → виправлення**.

## 1. Docker не запущений

- **Команда:** `docker compose up` (або будь-яка інша команда, що звертається до Docker)
- **Текст помилки:**
  ```
  docker.sock: no such file or directory
  ```
- **Причина:** Docker Desktop був закритий, тому Docker-демон не піднятий і сокет `docker.sock` відсутній.
- **Виправлення:** Запустити Docker Desktop і дочекатися повного старту демона, після чого повторити команду.

## 2. logging.info нічого не виводив

- **Команда:** запуск бота (`python app/main.py`)
- **Текст помилки:** помилки немає — просто відсутній вивід від `logging.info(...)` у консолі.
- **Причина:** Не було викликано `logging.basicConfig(level=logging.INFO)`, тому логер за замовчуванням ігнорував повідомлення рівня `INFO`.
- **Виправлення:** Додати `logging.basicConfig(level=logging.INFO)` на початку `main()` перед першим викликом `logging.info`.

## 3. Локальний запуск падав через Python 3.14 (pydantic-core)

- **Команда:** `python app/main.py` (локально, без Docker)
- **Текст помилки:** помилка збірки/імпорту, пов'язана з `pydantic-core`, при використанні Python 3.14.
- **Причина:** `pydantic-core` ще не мав стабільної сумісності з Python 3.14 на момент запуску.
- **Виправлення:** Запускати проєкт через Docker, де фіксується сумісна версія Python, замість локального інтерпретатора 3.14.
