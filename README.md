# ai-erp-print 
Це реальний проект
 Мета проекту
Проста внутрішня система для виробничої компанії, яка допомагає
оцифрувати й зв'язати внутрішні робочі процеси — обмін документами,
узгодження та відстеження статусів, що зараз розкидані по Excel-файлах.

Цільовий користувач
Співробітники виробничої компанії — менеджери, технологи, керівники.

Базові можливості
- Єдине місце для обміну робочими документами
- Узгодження заявок: заявка → погодження → статус (перший етап)
- Відстеження статусів процесів
- Поступова інтеграція з наявними системами компанії
